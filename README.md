# 악보 이조 — 웹용

PDF 악보의 멜로디와 코드를 원하는 키로 바꿉니다.
가사·줄바꿈·글꼴은 원본 그대로 둡니다.

**변환은 브라우저 안에서 끝납니다.** 악보 파일은 서버로 올라가지 않습니다.

## 주소

**https://voxhyeon-netizen.github.io/score-transpose/**

아이패드 사파리에서 열고 **공유 → 홈 화면에 추가** 하면 앱처럼 씁니다.

## 쓰는 법

위 주소를 열면 됩니다. 설치할 것은 없습니다.

인터넷에 올리면 주소 하나로 아이패드·윈도우·안드로이드 어디서나 쓸 수 있습니다.
아이패드 사파리에서 열고 **공유 → 홈 화면에 추가** 해 두면 앱처럼 씁니다.

### 올리는 법 (GitHub Pages 예시)

1. GitHub 에 저장소를 하나 만듭니다
2. 이 폴더의 파일을 올립니다
3. 저장소 Settings → Pages 에서 공개로 바꿉니다

비용은 들지 않습니다. 변환이 방문자 기기에서 끝나므로 서버는 파일 세 개를
보내 줄 뿐이고, 첫 방문에 약 233KB(압축 후), 그다음부터는 거의 0 입니다.

> 파일을 더블클릭해 여는 방식(file://)은 브라우저가 내려받기를 막는 경우가
> 있습니다. 바꾼 악보를 가져갈 수 없으니, 올려서 주소로 쓰는 편이 확실합니다.

## 두 가지를 바꿉니다

**악보 PDF** — 멜로디·코드·조표를 새 키로. 내려받기 전에 **미리보기**로 결과를 볼 수 있습니다.

**음원 파일** — mp3·m4a·wav 등의 **음높이만** 옮깁니다. 빠르기와 길이는 그대로라
반주에 맞춰 연주해도 어긋나지 않습니다. 가지고 계신 MR·반주 파일에 쓰세요.

> 유튜브에서 바로는 안 됩니다. 유튜브 플레이어는 소리를 바깥으로 내주지 않고,
> 내려받는 것은 유튜브 이용약관 위반입니다.
>
> 음높이만 바꾸는 처리는 원리상 소리가 조금 뭉개집니다. 반음 한두 개는
> 연습용으로 쓸 만하고, 그 이상 가면 티가 납니다.

## 구성

```
index.html         화면과 동작
engine.js          악보 이조 엔진
audio.js           음원 키 바꾸기
preview.js         악보 미리보기
pdf-lib.min.js     PDF 읽고 쓰기 (MIT)
pdf.min.js         미리보기 그리기 (Apache-2.0)
pdf.worker.min.js
soundtouch.min.js  음높이 바꾸기 (LGPL-2.1)
```

미리보기 도구(pdf.js, 1.4MB)는 **미리보기를 처음 누를 때에만** 받아 옵니다.
쓰지 않으면 받지 않습니다.
