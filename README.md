# 악보 이조 — 웹용

PDF 악보의 멜로디와 코드를 원하는 키로 바꿉니다.
가사·줄바꿈·글꼴은 원본 그대로 둡니다.

**변환은 브라우저 안에서 끝납니다.** 악보 파일은 서버로 올라가지 않습니다.

## 쓰는 법

`index.html` 을 열면 됩니다. 설치할 것은 없습니다.

인터넷에 올리면 주소 하나로 아이패드·윈도우·안드로이드 어디서나 쓸 수 있습니다.
아이패드 사파리에서 열고 **공유 → 홈 화면에 추가** 해 두면 앱처럼 씁니다.

### 올리는 법 (GitHub Pages 예시)

1. GitHub 에 저장소를 하나 만듭니다
2. 이 폴더의 파일을 올립니다
3. 저장소 Settings → Pages 에서 공개로 바꿉니다

비용은 들지 않습니다. 변환이 방문자 기기에서 끝나므로 서버는 파일 세 개를
보내 줄 뿐이고, 첫 방문에 약 233KB(압축 후), 그다음부터는 거의 0 입니다.

> 파일을 더블클릭해 여는 방식(file://)은 브라우저가 내려받기를 막는 경우가
> 있습니다. 바꾼 악보를 가져갈 수 없으니, 올려서 주소로 쓰는 편이 확실합니다.

## 구성
